# Документация

00_initial
Использованный метод:
Используется только базовый JSX без CSS. Все стили унаследованы от браузера или системных стилей.

 Инструкция по запуску:
npm install
npm run dev
01_css
 Использованный метод:
Подключение обычных CSS-файлов к каждому компоненту с помощью import './styles/Component.css'.

Особенности:
Простота и прозрачность.

Нет зависимости от сборщиков стилей.

Стили не изолированы, могут пересекаться.

02_scss 
 Использованный метод:
Используется синтаксис SCSS с переменными, вложенностью и импортом файлов в компоненты (.scss).

 Особенности:
Улучшенная читаемость кода за счёт вложенности.

Поддержка переменных и миксинов.

Требуется настройка и пакет sass.

 Инструкция по запуску:
Установка sass:

npm install sass

03_css_modules Использованный метод:
Используется CSS Modules вместе с SCSS — локализованные стили, подключаемые в виде объектов с классами.

 Основные особенности:
Локальная область видимости классов (избежание конфликтов имён).

Использование SCSS-переменных и вложенности.

Импорт стилей через import styles from './Component.module.scss'.

Присвоение классов через className={styles.className}

Необходима установка препроцессора

npm install sass

04_css_in_js — Стилизация с помощью styled-components
 Использованный метод:
Используется библиотека styled-components — реализация концепции CSS-in-JS, при которой стили создаются прямо внутри JavaScript/JSX-файлов как styled-компоненты.

 Основные особенности:
Инкапсуляция стилей на уровне компонентов.

Поддержка динамических стилей на основе props.

Нет необходимости в отдельных .css или .scss файлах.

Отлично работает с темами и глобальными стилями внутри JS

Инструкция по запуска нужна библиотека
npm install styled-components

05_css_framework — Стилизация с помощью CSS-фреймворка (Tailwind CSS)
 Использованный метод:
Используется Tailwind CSS — utility-first CSS-фреймворк, предоставляющий набор классов, которые можно комбинировать прямо в JSX, без написания собственных CSS-стилей.

 Основные особенности:
Utility-first подход: быстрая разработка с помощью готовых классов (text-blue-500, p-5, mb-2 и т.д.).

Полная кастомизация через конфиг tailwind.config.js.

Отсутствие конфликтов стилей, так как классы изолированы.

Быстрая стилизация без переключения между CSS и JS

06_component_library — Использование UI-библиотеки компонентов (Material UI)
 Использованный метод:
Для построения интерфейса применяется библиотека Material UI (MUI) — один из самых популярных React UI-фреймворков с готовыми адаптивными компонентами и темизацией.

 Основные особенности:
Используются предустановленные компоненты MUI (AppBar, Card, Typography, Container и др.).

Адаптивная и доступная верстка.

Стилизация через sx-проп и встроенные темы.

Отлично подходит для быстрой сборки интерфейсов и консистентного дизайна.

Инструкция по запуску:
Установка зависимостей, включая MUI:

npm install @mui/material @emotion/react @emotion/styled

# Контрольные вопросы 

1. В больших проектах предпочтительнее использовать CSS-in-JS или CSS-модули, так как они обеспечивают изоляцию стилей и предотвращают конфликты, улучшая масштабируемость и поддержку компонентов.

2. CSS-фреймворки ускоряют разработку и обеспечивают консистентный дизайн, но могут увеличивать размер файлов и ограничивать гибкость в кастомизации.

3. CSS-модули обеспечивают локальную область видимости стилей, предотвращая их глобальное распространение, в отличие от обычных CSS и SCSS, которые применяются глобально.

4. CSS-in-JS позволяет динамически генерировать стили в зависимости от состояния компонентов, но может ухудшать производительность и сложность кода по сравнению с обычными методами.
